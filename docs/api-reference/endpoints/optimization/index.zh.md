# Optimization 服务

:::warning 注意
该端点不属于 openrouteservice，而属于我们的公共 API。运行自己的 openrouteservice 实例时不可用。
:::

我们的公共 API 包含一个 VROOM 实例。VROOM 是一个用 C++20 编写的开源优化引擎，旨在在较少的计算时间内
为各种现实生活中的车辆路径问题（VRP）提供良好的解决方案。

关于如何使用它的详细信息可在我们的 [API Playground](https://openrouteservice.org/dev/#/api-docs/optimization) 中找到。

如果你需要更深入的了解，或想运行自己的实例，请访问 GitHub 项目 [VROOM](https://github.com/VROOM-Project/vroom)。
