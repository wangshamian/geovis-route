# 参与贡献
* [贡献代码](https://github.com/GIScience/openrouteservice/blob/master/CONTRIBUTE.md)
* [贡献翻译](Contributing-Translations)
* [更新 OpenStreetMap](https://wiki.openstreetmap.org/wiki/Beginners%27_guide)

当人们为 openrouteservice 做出贡献时，[整个团队](https://heigit.org/heigit-team/)都会开心地跳起舞来！有很多方式可以为让 openrouteservice 成为更好的路线规划服务做出贡献。
无论你是对修复一些 bug 或添加新功能感兴趣的 Java 开发者，是熟悉某个地区、能够更新 OSM 中的信息以便 openrouteservice 加以利用的人，还是会说不同语言、愿意为路线指示提供一些翻译的人，总有一件事是你可以帮忙的。

欢迎创建 [issue](https://github.com/GIScience/openrouteservice/issues) 并打上相应的标签。如果你的 issue 与 openrouteservice web-app 有关，请使用[对应的仓库](https://github.com/GIScience/ors-maps-client/issues)。
