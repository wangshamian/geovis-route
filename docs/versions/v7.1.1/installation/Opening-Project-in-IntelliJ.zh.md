# 在 IntelliJ 中打开 openrouteservice 代码

尽管 IntelliJ 提供了直接克隆仓库的功能，但下面是在 IntelliJ 中让 openrouteservice 运行起来的一般步骤：
1. 将仓库克隆到一个文件夹中
2. 打开 IntelliJ，通过 File -> New -> Project from Existing Sources 创建项目
3. 从克隆下来的 "openrouteservice" 文件夹中选择 "pom.xml" 文件，然后点击 "Open"
4. 点击 "Next" 逐步完成项目设置，直到进入选择项目 SDK 的页面。
5. 选择 "17" 作为项目 SDK，然后点击 "Next"
6. 在最后一个窗口中点击 "Finish" 完成项目导入。
