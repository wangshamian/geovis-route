# 结构化地理编码查询

结构化地理编码请求比普通请求更精确。它也非常适合从表格中查询位置。
对于结构化请求，请将至少包含以下参数之一的 JSON 对象插入到地理编码请求的 query 参数中：

  |   参数   | 描述                                                                                                                                                                                              |
  |:-------------:|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |    address    | 可以包含带门牌号的完整地址，也可以只包含街道名称                                                                                                                                       |
  | neighbourhood | 本地惯用的地理实体，未必是官方行政区划，但同样重要                                                                               |
  |    borough    | 主要在纽约市的语境中为人所知，不过其他城市（如墨西哥城）也可能存在                                                                                            |
  |    locality   | 城市名称                                                                                                                                                                                           |
  |     county    | 位于 locality 与 region 之间的行政区划                                                                                                                                                   |
  |     region    | 通常是国家内的一级行政区划，分别类似于美国和加拿大的州与省，不过大多数其他国家也设有 region |
  |   postalcode  | 邮政编码                                                                                                                                                                                             |
  |    country    | 国家名称。支持两字母和三字母缩写                                                                                                                                          |

## 示例

```json
{
  "address": "Berliner Straße 45",
  "locality": "Heidelberg",
  "country": "Germany",
  "postalcode": "69120"
}
```

## 难读化并编码后：

`%7B"address": "Berliner Straße 45","locality": "Heidelberg","country": "Germany","postalcode": "69120"%7D`
