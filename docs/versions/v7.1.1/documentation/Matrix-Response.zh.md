# 矩阵响应

矩阵响应会为每个指定的 `metrics` 值包含一个矩阵。
在该矩阵中，各项（行）对应 `sources` 的数量，每个项的条目（列）对应 `destinations` 的数量。

下面是一个简单示例，`sources=2,3`、`destinations=all`，共有 4 个 `locations`：

  | 位置 |    L0    |    L1    |    L2    |    L3    |
  |:--------:|:--------:|:--------:|:--------:|:--------:|
  |    L2    | L2 -> L0 | L2 -> L1 |     0    | L2 -> L3 |
  |    L3    | L3 -> L0 | L3 -> L1 | L3 -> L2 |     0    |
  
如果某个值无法确定，结果为 `null`。
