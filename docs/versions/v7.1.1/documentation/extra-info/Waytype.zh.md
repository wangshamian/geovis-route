# WayType

该 extra 提供路线相应部分道路类型的信息。

| 取值 |     名称     |
|:-----:|:------------:|
| 0     | 未知      |
| 1     | 州道   |
| 2     | 道路         |
| 3     | 街道       |
| 4     | 小径         |
| 5     | 小径（Track）        |
| 6     | 自行车道     |
| 7     | 人行道      |
| 8     | 台阶        |
| 9     | 轮渡        |
| 10    | 施工路段 |
