# 地理编码响应

返回参数说明

## 地点类型

描述返回的位置类型

  |      取值      |                                           描述                                           |
  |:---------------:|:------------------------------------------------------------------------------------------------|
  |     `venue`     | 兴趣点、商户、带围墙的场所                                               |
  |    `address`    | 带街道地址的地点                                                                    |
  |     `street`    | 街道、道路、公路                                                                        |
  | `neighbourhood` | 社会社区、邻里                                                              |
  |    `borough`    | 地方行政区划，目前仅用于纽约市                            |
  |   `localadmin`  | 地方行政区划                                                                 |
  |    `locality`   | 镇、小村、城市                                                                          |
  |     `county`    | 官方的政府辖区；通常大于 locality，几乎总是小于 region |
  |  `macrocounty`  | 相关联的一组 county。主要见于欧洲                                                     |
  |     `region`    | 州和省份                                                                            |
  |  `macroregion`  | 相关联的一组 region。主要见于欧洲                                                      |
  |    `country`    | 签发护照的地方、民族、民族国家                                             |
