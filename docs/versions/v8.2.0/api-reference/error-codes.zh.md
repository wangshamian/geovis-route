# 错误码

## HTTP 状态码

下表描述了受支持的 HTTP 状态码。

| HTTP 状态码 | 描述                                                                                                                                |
|:----------------:|--------------------------------------------------------------------------------------------------------------------------------------------|
| 200              | 请求处理成功时的标准响应。                                                                                                                 |
| 400              | 请求不正确，因此无法处理。                                                                                                                 |
| 404              | 端点不可用，或者给定的请求已成功完成但未找到结果。                                                                                         |
| 405              | 不支持指定的 HTTP 方法。更多细节请参阅端点文档。                                                                                           |
| 413              | 请求体积超出服务器能够处理的范围，请求中提供的数据超过了容量限制。                                                                         |
| 500              | 遇到了意外错误，并提供了更详细的内部错误码（参见[内部错误码](#internal-error-codes)）。                                                    |
| 501              | 表示服务器不支持满足该请求所需的功能。                                                                                                     |
| 503              | 服务器当前因过载或维护而不可用。                                                                                                           |
