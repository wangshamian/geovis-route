# Directions 服务

Directions 服务为不同交通方式计算两个或多个位置之间的路线和路线指引。

关于所有请求参数和返回类型的完整而简洁的概览，可以在 [API Playground](https://openrouteservice.org/dev/#/api-docs/directions_service) 中找到。
不过，这里会更详细地说明几个主题：

* 不同类型的 directions（即路径规划）[请求与返回类型](requests-and-return-types.zh.md)
* 如何定义高级的[路径规划选项](routing-options.zh.md)
* 如何请求[额外信息](extra-info/index.zh.md)，例如路面、道路类型、OpenStreetMap way ID 或额外的[路线属性](route-attributes.zh.md)
* 如何对 directions 响应中的几何数据进行[解码](geometry-decoding.zh.md)
* directions 响应中[指引类型](instruction-types.zh.md)的编码方式
