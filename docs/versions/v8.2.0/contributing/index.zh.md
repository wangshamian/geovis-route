# 参与贡献

我们很高兴你决定为 openrouteservice 做出贡献。

有很多方式可以帮助它成为一个更好的路由服务。
无论你是对修复
一些 bug 或添加一些新功能感兴趣的 Java 开发者，还是熟悉某个区域并
能够更新 OSM 中的信息以便 openrouteservice 将其
纳入考虑的人，又或者是会说不同语言并愿意为路由指引
提供一些翻译的人，总有你能帮上忙的地方。

欢迎创建 [issue](https://github.com/GIScience/openrouteservice/issues) 并为其打上相应的标签。
如果你的 issue 与 [maps.openrouteservice.org](https://maps.openrouteservice.org) 上的 openrouteservice 地图客户端有关，
请使用[相应的仓库](https://github.com/GIScience/ors-map-client/issues)。
