# 贡献

我们很高兴你决定为 openrouteservice 做贡献。

有很多方式可以帮助它成为更好的路径规划服务。
无论你是对修复
一些 bug 或添加新功能感兴趣的 Java 开发者，还是熟悉某个地区、
能够更新 OSM 中的信息以便 openrouteservice 加以利用的人，又或者是会说不同语言
并愿意为路线指示提供一些翻译的人，总有一些事情是你可以帮忙的。

欢迎创建 [issue](https://github.com/GIScience/openrouteservice/issues) 并为其添加相应的标签。
如果你的 issue 涉及 [maps.openrouteservice.org](https://maps.openrouteservice.org) 上的 openrouteservice 地图客户端，
请使用[相应的仓库](https://github.com/GIScience/ors-map-client/issues)。
