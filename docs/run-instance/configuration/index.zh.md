# 配置

openrouteservice 拥有大量配置属性。
这让 openrouteservice 成为一款高度可定制的软件。
[配置什么](what-to-configure.zh.md)章节
为你提供了 openrouteservice 所有配置属性的入口，
并且还向你展示了一个[最小配置示例](what-to-configure.zh.md#minimal-configuration)。

设置配置属性的方式有多种。
这同样为你运行 openrouteservice 的方式提供了灵活性。
但了解并理解不同的配置机制至关重要，
这样才能以期望的配置运行 openrouteservice。
在[如何配置](how-to-configure.zh.md)章节中，
我们处理配置主题的不同维度。

::: tip
使用专用的 YAML 编辑器（例如 [yamlchecker.com](https://yamlchecker.com)）来编辑配置。
普通文本编辑器常常会忽略语法错误。
:::
